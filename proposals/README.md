# SGIP Enhancement Proposals

An SEP proposes a change to what platforms or the hub must do: a new operation, a new op version, a change to signing, passports or the vocabulary rules. Small fixes and new vocabulary terms, other than stats, don't need one; see [CONTRIBUTING.md](../CONTRIBUTING.md).

There are no open proposals. Start one from the [template](0000-template.md).

Statuses: **Draft** → **Review** → **Accepted** (with the release it shipped in) or **Withdrawn**.
