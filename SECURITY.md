# Security

SGIP signs every request, issues passports and lets visitors spend money from their home game, so a flaw in the protocol can affect every game that uses it.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. If you can't use GitHub, email [hello@sgip.dev](mailto:hello@sgip.dev).

Include what you found, which part of the spec it affects (with the section number), and how to reproduce it. Never include real private keys or live passports.

We'll acknowledge your report, keep you informed while it's being fixed, and credit you when the fix is published, unless you'd rather stay anonymous.

## Scope

- The protocol itself: the specification, schemas, test vectors and anything they allow that they shouldn't.
- The tools, the website and the example and tutorial code in this repository.

A vulnerability in a particular game or hub implementation should be reported to whoever runs it.
